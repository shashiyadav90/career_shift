# Career Shifts Consulting — Premium React Landing Page

A responsive single-page website built with React, Vite, Framer Motion and Lucide React.

## Run locally

1. Install Node.js (18+ recommended).
2. Extract this project.
3. Open the project folder in VS Code or a terminal.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

- This is a frontend landing page with locally authored dashboard-style visuals.

- Replace generic social profile links with the organisation's official profile URLs before publishing.
